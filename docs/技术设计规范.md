## 数据流

```
Excel 源文件
    │
    ▼ (scripts/convert_excel_to_json.py)
按科类拆分的 JSON 文件
    │
    ▼ (src/utils/loadData.ts)
IndexedDB 缓存 → useDataStore (原始数据)
    │
    ▼ (src/hooks/useFilteredData.ts)
useFilterStore (筛选条件) → 筛选 + 排序 → 结果数组
    │
    ▼ (components/table/ResultTable.tsx)
虚拟化表格渲染
```

## 关键算法

### 选科匹配（超集逻辑）
```
输入: studentSubjects = {物理, 化学, 生物}, majorRequirement = "化学和生物"
处理:
  1. 分割 majorRequirement: "化学和生物" → ["化学", "生物"]
  2. 转换为 Set: {化学, 生物}
  3. 判断: required ⊆ studentSubjects → true (匹配)
特殊: "不限" → required = {} (永远匹配)
```

## 性能策略

1. **数据分片**：按科类+批次拆分为 4 个 JSON 文件，按需加载
2. **IndexedDB 缓存**：首次加载后持久化，后续访问 < 1 秒
3. **虚拟化表格**：只渲染可视区域内的 ~25 行 DOM 节点
4. **筛选顺序**：先执行选择度高的筛选（科类 50% → 批次 40% → 位次范围 60%），逐步缩窄
5. **搜索防抖**：300ms debounce
6. **useMemo 缓存**：筛选结果仅依赖项变化时重算
