# 晋辉高考数据分析卡 — 开发需求文档

## 项目概述

为山西省高考志愿填报规划师提供一个纯前端查询工具，输入位次和选科后，快速筛选出附近位次的院校专业组及专业信息。

## 目标用户

山西省高考志愿填报规划师（1人使用）

## 核心功能

### 1. 位次查询
- 用户输入精确位次（如 15000）
- 通过双向滑块调节浮动范围（±N 名）
- 默认范围：±2000 名

### 2. 选科匹配
- 用户选择自己的高考科目（物理/历史 + 化学/生物/政治/地理 中 4 选 2）
- 系统按「超集匹配」逻辑过滤：学生科目需覆盖专业要求的全部科目
- 「不限」选科要求的专业始终展示

### 3. 批次分离
- 按批次分 Tab 展示：本科批 / 本科提前批A段 / B段 / C段 / 高职专科批 / 高职专科提前批
- 每个 Tab 显示该批次的匹配结果数量

### 4. 多维度筛选
- 省份（多选）
- 城市（多选，随省份联动）
- 城市水平（一线/新一线/二线/三线/四线/五线）
- 院校标签（985/211/双一流/省重点/保研资格）
- 学校类型（综合/理工/师范/医药/财经/农林/政法/语言/艺术/军事/民族）
- 学费区间（滑块）
- 保研率区间（滑块）
- 学科评估（A+/A/A-/B+/B/B-/C+/C/C-）

### 5. 智能搜索
- 单一搜索框，支持按院校名称、专业名称搜索
- 支持拼音首字母搜索（如输入 qh 匹配 清华大学）
- 输入防抖 300ms

### 6. 结果展示（平铺专业级）
- 默认必展示字段：院校名称、专业组名称、专业全称、2025最低分、2025最低位次、学费、城市、保研率
- 可选展示字段：2024年数据、学科评估
- 默认排序：按位次从高到低
- 点击行展开/弹窗：2024年数据、学科评估、硕士点、博士点、专业水平等

### 7. 冲稳保分类
- 根据位次差距自动标注：冲刺（红）/ 稳妥（黄）/ 安全（绿）
- 侧边颜色条直观区分

## 非功能需求

- **纯前端**：无后端服务器，所有计算在浏览器完成
- **免费部署**：使用 GitHub Pages 免费托管
- **离线可用**：首次加载后数据缓存到 IndexedDB，后续秒开
- **响应式设计**：桌面端为主，兼顾平板和手机
- **数据版本**：仅 2025 年数据，无需更新机制
- **视觉风格**：简洁专业风（白底、卡片、适中信息密度）
